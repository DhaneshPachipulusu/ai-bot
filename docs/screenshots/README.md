# Screenshots

Drop the images here using exactly these filenames - the root README links to
them by name, so a correctly named file appears automatically with no further
edits.

| Filename | What to capture |
|---|---|
| `01-dashboard.png` | Home / dashboard - interviews completed, average score, recent interviews |
| `02-interview-setup.png` | Setup Your Session - resume upload and session configuration |
| `03-live-interview.png` | An interview in progress - question on screen, camera panel visible |
| `04-report.png` | Interview Report - radar chart, six scores, readiness badge |
| `05-report-delivery.png` | The "How you came across" panel with the delivery tiles |
| `06-learning-hub.png` | Learning & Preparation Hub - branch selection and topic cards |
| `07-resume-analysis.png` | ATS Analysis Report - the 79/100 score with section breakdown, not the upload screen |
| `08-admin.png` | Admin cohort view - per-student stats *(only if it is working)* |

PNG, full browser window, dark theme for consistency. Roughly 1600px wide is
plenty; anything much larger just makes the page slow to load.


## How to add them

1. Take the screenshot (browser at a normal window size, dark theme).
2. Save it into this folder with the exact filename from the table.
3. Uncomment the `<table>` block in the root README's Screenshots section -
   the markup is already written there.
4. Commit both.

A file named anything else will not appear, since the README links by name.

Windows note: `Win + Shift + S` captures a region; paste into Paint and save as
PNG, or use the browser's own full-page capture from devtools
(`Ctrl + Shift + P` -> "Capture full size screenshot").
